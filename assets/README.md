# Profile artwork

`research-light.svg` and `research-dark.svg` depict three distinct Weavidence paths: sources to learning, decisions to a protocol, and methods to results. The return lines represent retained context behind each output. They are not product screenshots, an integration diagram, a maturity scale or evidence of validation.

The geometry is identical in both themes. Native README text and image alt text carry the same meaning. All visible SVG labels are at least 36 viewBox units. GitHub supplies the surrounding typography and layout.

The SVGs contain no scripts, embedded fonts, animation or external resources. Keep the paths relative, maintain meaningful alt text and review the actual GitHub profile in both themes after any change.
